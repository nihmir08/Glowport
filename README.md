# Glowport

Moderner SSH-Client für Windows – Terminal, Dateien, Port-Forwarding und ein verschlüsselter Tresor in einem Fenster.
Modern SSH client for Windows – terminal, files, port forwarding and an encrypted vault in one window.

**[Download: neueste Version / latest release](https://github.com/nihmir08/Glowport/releases/latest)**

- `Glowport_<Version>_x64-setup.exe` – Installer, aktualisiert sich selbst / installer with automatic updates
- `Glowport_<Version>_x64_portable.zip` – portable Fassung / portable version

Windows zeigt beim ersten Start eventuell „Der Computer wurde durch Windows geschützt“, weil Glowport nicht mit einem
kostenpflichtigen Zertifikat signiert ist: „Weitere Informationen“ → „Trotzdem ausführen“.
Windows may warn on first start because Glowport is not signed with a paid certificate: "More info" → "Run anyway".
