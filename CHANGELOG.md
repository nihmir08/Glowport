# Changelog

Each version is listed here under `## <version>`. The section becomes the release text on GitHub and in Glowport's update dialog.

## 1.0.1

- After an update, Glowport names the new version on the next start.

## 1.0.0

First public release.

- SSH terminal with tabs, freely split panes, jump hosts, proxies, SSH agent and certificates
- Encrypted vault for hosts, groups with inheritance, identities, keys and snippets
- File manager for SFTP, FTP and FTPS, with a panel next to the terminal, resume and parallel transfers
- Port forwarding, snippets and macros, server info, Docker, services, processes and Proxmox
- Local terminal, Telnet, serial and Mosh
- Self-hosted sync server with end-to-end encryption and shared vaults
- Import from many programs, automatic updates
