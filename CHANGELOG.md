# Änderungen / Changelog

Jede Version steht hier unter `## <Version>`. Der Abschnitt wird beim Release zum Text auf GitHub und im Update-Dialog von Glowport.

Each version is listed here under `## <version>`. The section becomes the release text on GitHub and in Glowport's update dialog.

## 1.0.0

Erste öffentliche Version. / First public release.

- SSH-Terminal mit Tabs, frei teilbaren Fenstern, Sprung-Servern, Proxys, SSH-Agent und Zertifikaten
- Verschlüsselter Tresor für Hosts, Gruppen mit Vererbung, Identitäten, Schlüssel und Snippets
- Dateimanager für SFTP, FTP und FTPS, mit Leiste am Terminal, Fortsetzen und parallelen Transfers
- Port-Regeln, Snippets und Makros, Server-Info, Docker, Dienste, Prozesse und Proxmox
- Lokales Terminal, Telnet, Serial und Mosh
- Eigener Sync-Server mit Ende-zu-Ende-Verschlüsselung und geteilten Tresoren
- Import aus vielen Programmen, automatische Updates

- SSH terminal with tabs, freely split panes, jump hosts, proxies, SSH agent and certificates
- Encrypted vault for hosts, groups with inheritance, identities, keys and snippets
- File manager for SFTP, FTP and FTPS, with a sidebar next to the terminal, resume and parallel transfers
- Port forwarding, snippets and macros, server info, Docker, services, processes and Proxmox
- Local terminal, Telnet, serial and Mosh
- Self-hosted sync server with end-to-end encryption and shared vaults
- Import from many programs, automatic updates
